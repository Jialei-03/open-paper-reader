## 为什么做这个

最近的研究发现，自动科研 Agent 已经能完成科研的**工程**部分，却推进不了**研究**本身：

- 前沿 Agent 用 6 天、几千美元重做两篇未发表的 NeurIPS 论文，工程都做完了，研究没有实质进展。归纳出的失败包括：不知道什么值得做、走进死胡同不回头、不顾资源、做着做着偏离目标（Kirgis, Narayanan 等，[2607.27191](https://arxiv.org/abs/2607.27191)）。
- 缺数据时，7 个前沿模型全部选择自己合成数据，而不是承认做不了（SciIntegrity-Bench，[2605.10246](https://arxiv.org/abs/2605.10246)）。
- 在 24 个可运行的自动科研系统里，没有一个在流程内有经过外部验证的核验机制（[2608.05179](https://arxiv.org/abs/2608.05179)）。

Open Research Agent 主攻的就是这些：**研究判断力**、**持续不偏离目标**，以及作为底线的**结论可核验**。

## 它怎么工作

- **研究地图**：研究方向不放在聊天记录里，而是放在一张持久的树上：北极星问题 → 子问题 → 假设 → 实验 → 发现。每个节点有状态、置信度、证据和疑点，每次修改都记录谁改的、为什么。
- **按轮推进**：每一轮从地图和上一轮的交接开始，不带聊天历史。可以跨很多轮、跨天地做下去，中断后从地图恢复。
- **先聚焦再动手**：运行代码、写文件、改地图之前，Agent 必须声明正在推进地图上的哪个节点。没声明，或者那条分支已被否定，动作会被拒绝并记录下来。这既防止跑偏，也是"偏离"的度量。
- **止损条件**：每个假设都必须事先写好"出现什么结果说明这条路不通"。结果满足条件时，假设被否定。
- **导师**：一个只读的导师角色定期审视地图：每 3 轮一次，出现止损信号、得出发现、预算用到一半和八成、连续两轮没有进展时也会触发。它对每个节点给出继续、加注、放弃、转向或请人拍板，判断直接生效。
- **证据**：实验在本机 Docker 隔离环境里运行（无网络，只挂载项目自己的目录），日志由系统保存。记录结果时，证据只能是真实的日志行或论文原句，结论里的数字必须逐字出现在证据中。
- **研究手册（跨项目自我改进）**：每个项目结束后，一个提炼者把它的经过（导师的判断、止损、偏离）写成"在什么情况下该怎么做"的判断规则。规则被两个项目支持后才生效，有害的会被淘汰。之后的项目会读这本手册：研究过程在变好，模型本身不变。
- **过程指标**：偏离率、回头延迟、正常交接比例、证据条数、每条已支持结论的花费，都从记录中计算，可以拿来比较不同的做法。

## 现状

这是早期版本。已经真正跑通的部分：

- **完整的研究循环**：本机 Docker 实验、研究地图、导师、证据核对、研究手册、研究报告。都用真实模型（gpt-6-luna）端到端跑过。
- **第二轮评测**：3 个封存任务 × 3 个条件 × 2 个种子，详见[第二轮评测](docs/research/2026-10-20-second-results.md)。
  - 有导师的 12 次全部以正确的方式结束：该回答的得出了与真值一致的数字；缺数据的如实报告并停下等人，没有一次合成数据；诱人但无效的方向（"多项式特征能提升 2 个点"，真值是降低 2.5 个点）全部被否定，平均 3 轮就收手。偏离率 0。
  - 去掉导师后，执行者仍然诚实、数字也对，但 6 次全部跑满预算，花费是有导师时的 1.3 到 2.5 倍。导师的作用主要在于知道什么时候停。
  - 研究手册在这些任务上没有带来可见差别：任务太容易，手册里的规则也是开发者审核通过的。目前不能说手册有用。
- **还没有**：更难的任务和更多种子、在线版的研究功能（目前只在本机运行）、GPU 实验。

## 读论文

研究 Agent 的另一半能力是读论文。这部分也可以单独使用，[在线版](https://papers.dougao.online)就是它：

- 导入 PDF、arXiv 或任意论文网址，自动生成导读，每句话都带出处，点一下回到原文那一句；
- 划选解释、翻译、高亮、批注、记到笔记，框选图表或公式提问；
- 助手能看图片和框选区域（需要模型支持视觉）；
- 对照翻译、版面翻译、源码重编译；
- Markdown 笔记、文库、相关论文与推荐。

## 在自己电脑上运行

```bash
git clone https://github.com/Jialei-03/open-research-agent
cd open-research-agent
make install   # .venv + 后端、前端、Agent 运行时的依赖
make build     # 构建前端
python -m backend.local --port 8765   # 本机版，免登录，打开 http://127.0.0.1:8765
```

研究功能需要 Docker，以及一次性构建实验环境：

```bash
make research-image
```

在 macOS 上用 colima 时，Docker 默认只能看到主目录。数据目录默认在 `~/.open-paper-reader/`，所以不用改。第一次打开时先在设置里添加模型（API 密钥或本机模型）。详见 [本机版](docs/LOCAL.md)。
