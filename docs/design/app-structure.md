# 设计：应用结构与交互（参考 Codex / ChatGPT 桌面应用的交互逻辑）

参考的是交互逻辑：怎么组织、怎么导航、状态怎么呈现、操作放在哪里。内容和功能是 ORA 自己的：读论文、做研究、跑实验、得结论。不照搬对方的功能，也不做空壳入口。

## 总原则

1. **界面里不解释**：没有引导段落、副标题说明、提示语、「这里可以……」。空状态只有一个图标、一句短标题、一个按钮。文案只写名称和状态。
2. **概念要少**：用户只需要懂「项目」和「对话」。研究就是一段做了实验的对话，实验、轮次、地图都是对话里的内容。
3. **状态放在列表里**：进行中、等你、完成，用侧栏条目上的小图标和圆点表示，不另开一个页面。
4. **操作放在操作的对象旁边**：分叉在消息上，合并在变更上，暂停和停止在对话的菜单里。顶栏只放标题、菜单和面板开关。
5. **打开即有内容**：切换对话时先显示骨架或上一屏的内容，不出现整页空白加转圈。

## 左侧图标栏（固定）

|---|---|---|---|
| 研究 | 项目和对话 | 新研究、搜索、通知铃铛；项目（文件夹，可展开出其中的对话）；最近 | 对话 |
| 资料 | 论文库 | 全部、在读、未读、已读、发现；最近打开 | 论文列表（列表 / 卡片） |

| 自定义 | 技能和连接 | 技能（研究手册、各角色的做法）、连接（SSH 机器、实验追踪、模型） | 对应的管理页 |
| 设置（底部） | 账号、外观、数据 | — | — |

- 去掉「看板」分区，看板改为项目页里的一种视图。
- 去掉现在那个状态汇总版的「任务」分区，那些信息已经由侧栏状态和通知铃铛承担。
- 「资料」里不再放首页。打开应用默认进入「研究」的新研究页。

### 定时任务（我们自己的内容）

和 Codex 的定时任务交互一样：列表、新建、暂停、下次执行时间。任务本身是科研的事：
- 每日论文速递：按关键词、作者或会议，每天把新论文整理进资料库，并发一条摘要；
- 每周研究周报：汇总一个项目里本周的进展和结论；
- 跟踪一个研究：定时检查实验，出结果或出错时通知；
- 夜间复跑：在空闲的机器上按计划复跑实验或补种子。

到点时，它就在指定项目里开一段新对话，或者往已有对话里发一句话，结果和普通对话一样出现在侧栏，带未读圆点。没有建议卡片以外的说明文字。

## 研究分区

### 侧栏
- 顶部：工作区名称和下拉、通知铃铛（有需要你处理的事时带圆点，点开是列表）、搜索。
- 「新研究」。
- **项目**：一行一个，只显示名称，机器不放在这里。展开后是它的对话，最多显示 5 条，其余收进「展开显示」。悬停时出现「+」，用来在这个项目里新开对话。
- 对话从别的对话派生出来（子研究或分叉）时，缩进显示在父对话下面。
- **最近**：不分项目的最近对话。
- 条目右侧的状态：转圈表示进行中，蓝点表示未读或等你，没有标记表示完成或空闲。
- 去掉「项目导师」这种特殊条目。项目里的每段对话都有导师的能力：读整个项目、派出子研究。

### 新研究页（新对话）
- 居中一句「想研究什么？」（项目名用下拉选择，不拼进句子），下面是输入框。
- 输入框底部左侧：「+」（附加论文或文件）、项目；右侧：模型、发送。不显示机器：机器由项目决定，在项目设置里看和改。

### 对话页
- **顶栏**：项目图标、对话的短标题（自动生成，十来个字，不是整句问题）；右侧是「⋯」菜单（重命名、分叉、暂停/继续、停止、归档）和右侧面板开关。顶栏不显示状态文字，不放分叉、合并按钮。
- **对话流**：
  - 研究者的话是右侧气泡。
  - 每一轮 agent 的工作折叠成一行「用时 3 分 12 秒 ›」，点开看步骤；后面跟着这一轮最后说的话。
  - 计划是一张卡片，上面有「开始实验」。
  - 这一轮改了文件时，接一张「已修改 N 个文件 +a −b」卡片，带「撤销」「查看变更」（每轮有检查点提交，可以直接对比）。
  - 跑了实验时，接一张实验卡片：名称、机器、状态、关键指标。
  - 结论是一张卡片，上面有「接受」「再做一轮」。
  - 消息悬停时出现：复制、从这里分叉、时间。
- **输入框**：只有「接着说」一个占位词，不写解释。

### 右侧面板（可开关，浮在右边的一张卡片，不分页签）
按顺序列出存在的部分，没有内容的部分不显示：
- **变更**：相对项目主线的 `+a −b`，点开看逐文件的对比；有「合并到项目」。
- **子研究**：派生出去的研究，带状态图标，以及「N 完成」这样的汇总。
- **实验**：正在跑和最近跑完的实验，带机器名。
- **计划**：当前计划的假设和进度（研究地图的精简版）。
- **来源**：用到的数据集、论文、上传的文件；有「+」可以添加。

### 项目页（点项目名进入）
- 标题、对话列表（可在列表和看板之间切换）、项目说明、默认模型和机器。

## 资料分区

参考 ChatGPT 资料空间的交互：右上角搜索和「导入」；分类只放在侧栏，主区不重复放筛选；列表 / 卡片切换；表头是名称、来源、上次打开时间。

## 不做的

- 不为没有实现的能力放入口：没有插件市场，就不放插件页。
- 不在任何页面写功能介绍。
- SSH 机器不设「用哪几张 GPU」：执行者每次看 nvidia-smi，自己挑空闲的卡。
