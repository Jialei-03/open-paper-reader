# 设计：团队聊天参照飞书

研究团队的聊天不再参照 Slack（用户 2026-10-24 确认：频道与私信合并为一个按最近活动排序的列表；我的消息靠右、浅强调色气泡），参照飞书的消息页和 Codex / MiniMax 的产出面板。界面只有标签，不加说明文字。

## 三栏
- 左：会话列表（项目侧栏里的团队部分）
  - 顶部一排常用成员头像（点开私信）。
  - 「线程」「提及我的」两个入口，带未读数（红色数字徽标）。
  - 「消息」：频道和私信一个列表，按最近活动排序，可置顶。每行：头像（频道用 # 方块，成员用彩色圆头像 + 状态点），名字，右上时间，第二行最后一条消息预览「作者：内容」，有未读时右下红色数字；成员工作中时第二行显示「工作中…」（强调色）。
- 中：聊天
  - 标题栏：名字，人数「人 1 · 智能体 6」，右侧图标：搜索、文件、侧边面板开关。
  - 我的消息靠右，浅强调色气泡；成员消息靠左：彩色圆头像，名字 +「智能体」标签，浅灰卡片气泡。
  - 卡片里：工具调用折叠成一行（「查论文 · 读网页 ×2」，点开看过程），正文，产出文件为文件卡片（图标、文件名、打开）。
  - 卡片下一行：交接去向「交给 写手」、模型、时间、「N 条回复」（强调色链接）；悬停出现复制、回复、停止。
  - 排队中：一行「头像 名字 排队中」。
  - 私信空状态：成员名片（头像、名字、简介、模型、工具）。
  - 输入框：占位「发送给 <会话名>」，右侧 @、附件、发送；成员工作中时出现「立即发送」。
- 右：侧边面板（可收起，记住开关）
  - 进度：当前会话里工作中 / 排队中的成员。
  - 交付物：本会话产出的文件，点开预览。
  - 来源：引用过的论文。

## 视觉
- 层级：页面底色 < 卡片；列表行悬停与选中用现有 ghost hover / selected 填充。
- 文字对比：正文用主文字色，次要信息用次级色，只有时间等元数据用最弱色。
- 头像颜色来自 agent 文件的 color，频道头像统一中性色。
- 不新增尺寸变量，沿用 frontend/src/ui/tokens.css。
