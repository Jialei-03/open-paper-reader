# 纸间 · 标志

标志是一本竖立的黑色书：保留顶部的斜向页边，中间沿书脊有一道窄而平滑的弧形页缝。深色模式下界面里反白显示。

| 文件 | 用途 |
| --- | --- |
| [`frontend/public/assets/icons/zhijian-book-v5.svg`](../../frontend/public/assets/icons/zhijian-book-v5.svg) | 矢量版，界面里的标志和 `favicon.svg` 的来源 |
| `frontend/public/assets/icons/zhijian-book-v5.png`、`.ico` | 浏览器标签页图标 |
| `frontend/public/assets/icons/zhijian-book-touch-v5.png` | iPad / iOS 添加到主屏幕的图标 |
| [`zhijian-book-v5-approved.png`](zhijian-book-v5-approved.png) | 定稿的位图参考，矢量版按它的轮廓重绘 |
| [`zhijian-book-v5.png`](zhijian-book-v5.png) | 同一轮廓的小图 |

标签页与触控图标由矢量版统一导出。修改标志时请保持：竖立的书本外形、黑色块面、顶部的斜向页边，以及窄而平滑的书脊页缝（不要换回大块的白色三角）。

标志随仓库按 MIT 许可证提供，但许可证不授予商标权，见 [NOTICE](../../NOTICE.md)。
