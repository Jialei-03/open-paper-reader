# 离线阅读（第一版）

在普通浏览模式中登录纸间，打开一篇 PDF，点击阅读工具栏中的下载图标，然后选择「保存供离线使用」。等待显示下载完成，再从侧栏底部「本机论文 · 离线使用」进入本机阅读器。第一次会同时下载阅读界面和 PDF 所需资源。

本机阅读器可以在断网、关闭浏览器并重新打开后读取已保存的 PDF，并编辑已下载的文字笔记。笔记自动保存到当前浏览器的 IndexedDB；等待「已保存到本机」再关闭页面。恢复网络时会尝试同步，也可点击「同步笔记」。同步需要登录下载这些论文的原账号。

云端笔记已被修改或删除时，不覆盖任何一方。本机内容保留，可导出备份，或选择「另存为新笔记并同步」。有未同步笔记的论文不能移除本机下载。移除下载不会删除云端论文。

第一版支持 PDF 翻页和已有笔记的 Markdown 文字编辑。批注、全文搜索、创建新笔记、新的 AI 请求、翻译和论文导入仍需联网使用在线工作区。安装到主屏幕不是必需条件。

数据保存在当前设备和浏览器；换设备、清除网站数据、无痕模式结束或浏览器回收存储可能导致本机副本丢失。云端已同步的数据不受影响；重要的未同步内容请使用「导出本机笔记」保存备份。应用会请求持久存储，但浏览器是否批准由浏览器决定。

## 验证

浏览器验收覆盖 Chromium 和 WebKit：下载、断网编辑、关闭整个浏览器后重启、PDF 和笔记持久保存、重复同步幂等，以及云端冲突保留与副本同步。WebKit 通过断开测试源站连接验证，不依赖有缺陷的离线模拟接口。实际 Safari/iPad 的系统存储回收和长时间后台行为仍需设备验证。
