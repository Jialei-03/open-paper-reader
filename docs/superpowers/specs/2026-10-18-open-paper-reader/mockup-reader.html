A-Mem: Agentic Memory for LLM Agents

Wujiang Xu, Zujie Liang, Kai Mei, Hang Gao, Juntao Tan, Yongfeng Zhang
1  Introduction
Large Language Model (LLM) agents have demonstrated remarkable capabilities in various tasks. Existing memory systems require developers to predefine memory storage structures and retrieval timing. In this paper, we introduce a novel agentic memory system, named A-MEM. Our approach draws inspiration from the Zettelkasten method, a sophisticated knowledge management system that creates interconnected information networks through atomic notes and flexible linking mechanisms. For each new memory, we construct comprehensive notes that integrate multiple structured attributes, including keywords and tags, and embeddings for similarity matching.
