# 功能

纸间围绕「读一篇论文、记下来、攒成自己的知识」设计。研究助手贯穿其中，但不是唯一的入口：不接模型也能导入、阅读、批注、写笔记、整理文库。需要模型的功能在下面标出。

## 论文与文库

- **导入**：上传 PDF（可拖入页面任何位置，一次多篇），或粘贴 arXiv 的 abs、html、pdf 链接。arXiv 论文锁定版本，元数据优先取官方 API，同一版本不会重复导入。
- **文库**：阅读状态（未读 / 阅读中 / 已读）、收藏、归档、标签、研究方向、集合；紧凑或详细列表，筛选与排序。研究方向可以重命名、合并，相关论文和笔记的标签同步更新。
- **批量整理**：勾选多篇后收藏、归档、加标签、加入集合、导出 BibTeX；选 2–5 篇还可以让助手比较（需要模型）。
- **全局搜索**：`⌘K`（Windows 为 `Ctrl+K`）同时搜论文和笔记。
- **发现论文**：按你的研究方向搜索 arXiv，自动排除已入库和已归档的论文；可以写一份研究偏好文档，忽略或标记「不感兴趣」，反馈可撤销。只在你点击按钮时访问外部服务，不做后台抓取。
- **知识图谱**：笔记和论文之间的链接（`[标题](#paper/…)`、`[标题](#item/…)`）自动形成双向链接，可以从任意论文或笔记进入局部图谱，沿着主题、证据和问题继续读。
- **分享与导出**：为一篇论文创建只读分享链接（有效期、是否附带笔记，可随时撤销）；下载原文件或带批注的 PDF；一键导出整个工作区（论文、附件与笔记）。
- **账户**：用户名登录，每个账户独立空间；邮箱可选，只用于找回；还可以为自己的 Agent 创建只读或可写的 API 凭据，随时撤销（见 [API](API.md)）。

## 阅读与批注

- **阅读器**：连续滚动或翻页，缩放、旋转，目录与缩略图，全文查找；缺少目录时可以从正文生成。悬停章节或引用标记，弹出目标位置的原文裁片；外部链接显示来源提供的标题与摘要。侧栏可以停靠在右侧或底部，也可以收起。
- **划选菜单**：选中文字后解释 `E`、高亮 `H`、翻译 `T`、评论 `C`、向 AI 提问 `Enter`、复制、摘录；选区可以跨页，右键菜单相同。
- **框选**：圈出图表、公式或表格，用四角调整范围；解释图表、转写公式、翻译框内文字（模型能识图时连图片一起看）、复制为图片（`⌘C`，可以直接粘贴到笔记或 AI 对话）。
- **批注**：五种高亮颜色、原文评论，在「批注」面板里回看、搜索、导出；手写笔和橡皮直接作用于页面，触控笔书写、手指滚动。
- **笔记**：每篇论文默认一篇阅读笔记，可以再添加；Markdown、公式、图片、表格、任务清单，保存状态随时可见，历史可回看，可导出为带图片的压缩包。笔记之间、笔记与论文之间用链接相连；「来源」链接指向论文的具体页（在笔记里按住 `⌘`/`Ctrl` 点击跳转）。
- **图表目录**：列出全文的图与表和页码，一键定位或解释；也可以让模型识别当前页的图表与公式（需要[可选组件](DEPLOYMENT.md#图表与公式识别)）。
- **引用文献**：参考文献与被引用的论文，可以收藏、复制、导入文库。通过 Semantic Scholar 查询，只发送论文公开的 DOI 或 arXiv 标识。
- **深色模式**：跟随系统，或在设置里固定。

## 翻译

详见 [翻译](TRANSLATION.md)。

- **对照翻译**：逐页、逐句与原文并排，悬停译文时原文里对应的句子亮起；宽屏左右排列，窄屏上下排列。需要模型。
- **选段翻译**：选中文字即时得到译文，需要更准时用「AI 精译」，结果保存在翻译面板，可以搜索与导出。
- **整篇翻译**：提供 LaTeX 源码的 arXiv 论文，译成排版完整的中文 PDF，公式和图表原样保留，可以单看译文、并排查看、合并下载。需要模型和[翻译组件](DEPLOYMENT.md#整篇论文翻译arxiv-的-latex-源码)。
- **版面翻译**：没有源码的 PDF，通过可选的 BabelDOC 镜像识别版面后重新排版。需要模型和[版面翻译组件](DEPLOYMENT.md#普通-pdf-的版面翻译)。

## 研究助手

详见 [助手](AGENT.md)。需要模型。

- **实际读取原文**：回答之前读取你指的那一页、那个区域或整篇论文，而不是凭印象；回答带着页码，看不清或没读到的会直说。
- **在阅读器里问**：选中文字、框住图表或公式、对整页或整篇提问，助手拿到的是你指的那一块和它所在的页。
- **比较多篇论文**：在文库里勾选 2–5 篇，助手逐篇读取全文，按研究问题、方法、数据、结果与局限整理成表格，每一项标明出自哪一页。
- **动手整理**：写进笔记、给论文打标签、导入 arXiv 论文、发起全文翻译。修改文库默认需要你允许，写入后回读核对并给出可点开的凭证。
- **可核对**：每个回答可以展开「N 项操作」，看到它读了哪几份文件、做了什么修改。
- **论文导读**：关键词、三行摘要，研究问题、方法、结果与边界，每一条标出证据页；**阅读测验**：选择题数与难度，作答后看分数、解析和证据；**重点建议**：按创新、方法、结果标出值得细读的句子，可以叠加显示在论文上，不会覆盖你的批注。
- **模型**：每个账户添加自己的模型，部署者也可以提供共享模型；按模型支持的参数选择思考强度。

## 界面语言

界面目前只有简体中文。论文和模型输出可以是任何语言；翻译的目标语言目前是简体中文。
